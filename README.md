One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, judged head to head by an AI.

> I'm on vacation until Monday. My replacement model is answering your emails — it charges by the token and has already billed you for reading this.

The joke is the handover: the agent is away, and the stand-in model it left behind has already started charging the sender for the privilege of being answered. `main.ts` writes exactly that line (146 characters, one line) to `/output/entry.txt`.
